# 시월 — 찢어지는 고요 (October Kinetic)

A 30-second kinetic-typography film about October, made with [HyperFrames](https://github.com/heygen-com/hyperframes) (HTML → MP4).

Dawn stillness for 14 seconds, then the drop: autumn landscapes are torn open inside giant Korean letters, cut on the beat.

- **Watch:** https://willofgodyejun.github.io/motiongrahpic/
- **Video file:** [`docs/october-kinetic.mp4`](docs/october-kinetic.mp4) — 1920×1080, 30 fps, 30 s
- **Shots and timing:** [`SPEC.md`](SPEC.md) · storylines: [`STORYLINES.md`](STORYLINES.md) · review notes: [`REVIEW.md`](REVIEW.md)

| Time | Beat |
| --- | --- |
| 0–7 s | 새벽 호수 · "시월, 아침" drops onto the water one letter at a time |
| 7–14 s | 안개 · "바람이 먼저 물든다", the letters dyed vermillion on the music |
| 14–24 s | Drop · 붉게 / 더 / 붉게 / 타오르듯 / 흔들리고 / 물들고 / 시월, beat-cut photos inside the letters |
| 24–27 s | 단풍 한 가지 · "떨어지는 것도 아름답다" |
| 27–30 s | 시월 · OCTOBER |

## Edit and re-render

```bash
npx hyperframes preview   # Studio preview
npx hyperframes check     # lint, layout, contrast
npx hyperframes render    # MP4 into renders/
```

The Korean faces are macOS system fonts (AppleMyungjo, Apple SD Gothic Neo), so render on a Mac.
